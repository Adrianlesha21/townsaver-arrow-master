## Controls
| Action | Keys |
| :--- | :--- |
| **Move & Aim (`▲ ▼ ◀ ▶`)** | `WASD` or `Arrow Keys` |
| **Fire Bow (Facing Direction)** | `Space`, `Enter`, or `F` |
| **Select Weapon** | `1` (Single ∞), `2` (Double Shot), `3` (Great Arrow), `Tab` / `Q` |
| **Story Scroll / Pause / Restart / Mute** | `B` / `P` / `R` / `M` |
